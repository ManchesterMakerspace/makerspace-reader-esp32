# Provisioning implementation status

This implementation is incomplete. Do not deploy it as the planned provisioning release.

Implemented in the reader: resolved flash-size profile selection (4/8/16 MB), isolated staged builds, partition generation and bounds tests, 10% image-headroom check, build/physical-flash statistics, startup layout validation, profile-specific storage limits, scoped compact refresh, persisted card recency and privileged/session-owner pinning. The 4 MB profile now uses two 1.625 MiB app slots and 700 KiB LittleFS; moving from its earlier layout requires a factory reflash. GitHub firmware CI builds all three profiles both with and without Wi-Fi.
